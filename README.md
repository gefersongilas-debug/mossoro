# Mossoró Empresarial — Landing Page

Landing page da Mossoró Empresarial, construída com Next.js, React, TypeScript e GSAP.

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Publicação

O projeto está na raiz do repositório para funcionar diretamente em Vercel, Netlify ou outro serviço compatível com Next.js. O formulário direciona os pedidos de cotação para o WhatsApp comercial da Mossoró.
